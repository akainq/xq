XQ is a compiled language for concurrent programs. It reads like TypeScript and is built like Erlang: lightweight processes talk through typed messages, a crash stays inside its process, and supervisors restart it. Programs compile to native code through LLVM — no garbage collector, no virtual machine.

counter.xq
type Msg =
  | { type: "inc"; by: int }
  | { type: "get"; replyTo: Pid<int> };

// A process is a function; its state lives in
// the arguments of a tail call.
function counter(this: Process<Msg>, value: int): void {
  receive {
    { type: "inc", by } => counter(value + by),
    { type: "get", replyTo } => {
      replyTo.send(value);
      counter(value);
    },
  }
}

function main(this: Process<int>): void {
  const c = spawn(counter, 0);
  c.send({ type: "inc", by: 42 });
  c.send({ type: "get", replyTo: self() });
  receive {
    n => console.log("value:", n),
  }
}
$ xq run counter.xq
value: 42

Data never changes. The rest follows.

Most of what makes concurrent programs hard — races, locks, one failure taking down everything — comes from mutable state shared between threads. XQ takes mutation out of the language and builds on what is left.

Immutable by design

No let, no assignment, no mutating methods. New values are built from old ones — { ...p, x: 1 }, [...xs, x], xs.with(i, v) — and any value can be read from anywhere.

Processes, not threads

Processes with heaps of their own — about 6 KB each, a million at once — exchange messages. receive takes the first message that matches a pattern, and a preemptive scheduler spreads processes over every core.

No garbage collector

Immutable values cannot form cycles, so reference counting frees memory right after its last use, and counts need no atomics. A value with a single owner is updated in place: appends and record updates cost amortized O(1).

Failures stay local

Integer overflow, an index out of bounds, a pattern that does not match, stack overflow: only the process crashes, and its heap is freed whole. Links and monitors tell the others; a supervisor restarts it.

Loops are recursion

Tail calls are guaranteed, so a process keeps its state in the arguments of its loop and the stack never grows. for (const x of xs) walks collections.

Typed protocols

A message is an ordinary value, so a protocol is a type: records and unions with literal tags. The compiler knows the mailbox type of every function — a message of the wrong type does not compile.

Fast where it matters

The same programs written in each language, on one machine. Higher is better for requests, lower for time.

Batteries included

Waiting stops only its own process: sockets live on an event loop, and errors are values of Result<T>. Everything a server needs is in the standard library.

  • std/netTCP, TLS and UDP; length-prefixed frames delivered as messages; one datagram to many addresses
  • std/httpHTTP/1.1 server with a process per connection, fetch, HTTPS and WebSocket
  • std/rtcWebRTC transport for media servers: ICE-lite, DTLS 1.2, SRTP
  • std/cryptorandom bytes, HMAC-SHA256, AES-GCM, Ed25519
  • JSON.parse<T>parses text straight into compiled values of the type, checking it on the way
  • Binarycompact binary messages from types, encoders and decoders made by the compiler
  • std/supervisorrestart strategies, restart limits, supervision trees
  • std/execrun programs with pipes or a pseudoterminal; they die with their process
  • std/gpuwindows and 2D graphics on Vulkan: sprites, shapes, text, custom WGSL materials
  • declare librarycall C functions from any shared library, 7–17 ns per call
  • RegExpregular expressions with linear-time matching: a pattern cannot hang a process
  • Uint8Arraytyped arrays; their buffers travel in messages without copying

Tools in the box

  • Projects and tests. xq.toml, xq build, xq run, and xq test runs the tests in parallel and checks that no process leaks memory.
  • Packages. xq add qr takes a package from the registry — any public git repository with version tags — and xq.lock keeps the exact commits.
  • A language server. xq lsp: errors as you type, types on hover, go to definition, completion by type. It also marks every update that copies a shared value, and says why.
  • Debugging. xq build -g gives native debuggers XQ's values — records, arrays, maps, process ids — and every live process with its mailbox.
  • One format. xq fmt has no options, on purpose.
  • No silent hangs. When every process waits for a message that cannot come, the program exits and says so.
import * as supervisor from "std/supervisor";

// Restart a crashed child, at most 5 times in 10 s;
// on the way out, stop the children in reverse order.
function startApp(): Pid<supervisor.Msg> {
  return supervisor.start({
    strategy: "oneForOne",
    intensity: 5,
    period: 10000,
    children: [
      { id: "db", start: () => spawnLink(db) },
      { id: "web", start: () => spawnLink(web, 8080) },
    ],
  });
}

Built with XQ

Video meetings

A Zoom-like service — server, browser client and native client, with voice, video and noise suppression — written in XQ and running in production. Its server delivers a message to a 100,000-member channel 14% sooner than the same server written in Go, with 14–19% less CPU and a quarter of the memory, and relays 37% more voice streams per core.

A terminal emulator

A VT parser, scrollback in typed arrays, 24-bit color, mouse and clipboard; the whole screen is sprites from one glyph atlas on the GPU. PowerShell, bash, vim and htop run in it at the display's refresh rate, and if the parser crashes, a supervisor brings the screen back in 2–3 ms.

Install

An archive holds xq and the runtime libraries next to it. XQ compiles with clang 15 or later, which you need on the machine.

Windows

  1. Install LLVM (clang) and the C++ build tools of Visual Studio.
  2. Unpack the archive and add its folder to PATH.

Linux

  1. Install clang: sudo apt install clang. glibc 2.39 or later: Ubuntu 24.04, Debian 13.
  2. Unpack: tar xf xq-0.10.0-x86_64-linux.tar.gz, and add the folder to PATH.

macOS

  1. Install the command line tools: xcode-select --install.
  2. Download with curl -LO, or after a browser download allow the files: xattr -dr com.apple.quarantine xq-*. Unpack and add the folder to PATH.
